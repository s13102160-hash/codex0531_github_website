# 我的第一個 GitHub Pages 網站

這個專案用來練習：

- 建立最基礎的 HTML/CSS 靜態網站
- 使用 Git 管理版本
- 上傳到 GitHub repository
- 透過 GitHub Pages 發布網站
- 用學習紀錄保存每一步操作

## 檔案說明

- `index.html`：網站首頁
- `styles.css`：網站樣式
- `docs/github-basic-website/`：穩定版學習筆記
- `logs/`：每日操作紀錄

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可預覽。

## GitHub Pages 發布方式

1. 在 GitHub 建立一個新的 repository。
2. 將本機專案推送到 GitHub。
3. 到 repository 的 `Settings` -> `Pages`。
4. 在 `Build and deployment` 選擇從 branch 發布。
5. 選擇 `main` branch 和 `/(root)` 資料夾。
6. 儲存後等待 GitHub Pages 產生網站網址。

參考：GitHub 官方文件說明 GitHub Pages 可以直接從 repository 中的 HTML、CSS、JavaScript 發布靜態網站。
