# GitHub 基礎網站學習索引

## 學習主題

透過 Codex 建立一個最基礎的 GitHub Pages 靜態網站，並把操作過程整理成可回放的學習紀錄。

## 學習目標

- 認識靜態網站的最小檔案組成：`index.html` 和 `styles.css`
- 知道 GitHub Pages 適合發布 HTML、CSS、JavaScript 靜態內容
- 學會把本機資料夾變成 Git 專案
- 學會之後如何把專案推送到 GitHub
- 保留每日操作紀錄與問題排查紀錄
